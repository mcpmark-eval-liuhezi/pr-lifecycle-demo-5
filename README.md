# pr-lifecycle-demo-5

This repository is a sandbox built for a **new-engineer onboarding session**. It walks through a complete GitHub pull-request lifecycle: starting from an idea on a feature branch, opening a draft pull request, pruning it down to a focused change set, flipping it out of draft, and then leaving it open for real reviews and status checks so the whole loop is visible in one place.

## What is in here

- `README.md` — this file, an explanation of what the demo is for
- `greeter.py` — a small Python script that prints a friendly greeting

## The story

The original version of `greeter.py` prints a short, businesslike greeting. Later, a separate branch changes that greeting text to something friendlier, and a draft pull request compares them.

## Notes

This is an intentionally scratch repo. Nothing in it should be treated as production code, and it is perfectly fine to delete after the session.
